# Contributing to 1MB

Thank you for helping improve the public documentation, configuration examples, scripts, and resources maintained for 1MoreBlock.com.

## Before You Start

- Search the existing GitHub Issues before opening a new one.
- Keep each change focused and explain which problem it solves.
- State the Minecraft, Paper, Java, operating-system, or plugin versions relevant to your change.
- Never include passwords, API keys, license keys, private player information, production logs, premium plugin JARs, or other material you do not have permission to share.

## Making a Contribution

1. Fork or clone the repository and create a focused branch.
2. Make the smallest practical change that solves the problem.
3. Test scripts and configuration changes in a safe, non-production environment.
4. Update related documentation when behavior or usage changes.
5. Open a pull request describing what changed, why it changed, and how you tested it.

## Documentation and Configuration

- Use clear English and keep examples concise.
- Preserve existing formatting unless reformatting is part of the proposed change.
- Do not assume every resource targets the current live-server version; identify compatibility clearly.
- Remove or redact private server data before committing examples.

## Issues and Support

Use GitHub Issues for bugs or improvements involving files in this repository. Gameplay questions, account help, and third-party plugin support should use the community or the relevant plugin author's support channels instead.
