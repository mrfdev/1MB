# 1MB – 1MoreBlock.com Minecraft Server 🎮

Welcome to the official repository for 1MoreBlock.com (1MB). It contains public documentation, configuration examples, scripts, and other resources related to the server.

---

## 🌐 Overview

**1MoreBlock.com (1MB)** is run by a dedicated team of players and staff, built for builders, redstone engineers, explorers, and casual gamers.  
We operate a **standalone Minecraft 26.2 server** using [Paper 26.2 server software](https://papermc.io/downloads/paper), providing multiple game modes, quality-of-life enhancements, and a friendly, welcoming environment.

---

## ⚙️ Features

- **Multiple Game Modes:** Survival, Creative, OneBlock, Skyblock, Events, and more
- **Custom & Popular Plugins:** Open-source, premium, and unique in-house enhancements
- **Performance-Oriented:** Hosted on modern Apple hardware (M1, M2 Pro, M4 Pro)
- **Active Community:** [DiscordSRV](https://scarsz.me/discordsrv) integration, regular events
- **Safe Environment:** Experienced moderation, clear rules, and a family-friendly community

---

## 🚀 Quick Start

1. **Connect:**  
   - Java Edition 26.2: `1moreblock.com:25565`
   - Bedrock Edition: `1moreblock.com:19132` via Geyser with Floodgate authentication

   Java players must currently use Minecraft 26.2; other Java client versions cannot connect. Bedrock players must use a version currently supported by [Geyser](https://geysermc.org/wiki/geyser/supported-versions/).
2. **Read Rules:**
   [Server Rules](https://rules.1moreblock.com)
3. **Join Community:**
   Ask questions on [Discord](https://discord.gg/floris)—staff and regulars are happy to help!

## 🛠️ Server Details

- **Live Server:** `live-1mb-3.13.2-mc-26.2`
- **1MB Era & Version:** Era 3, version 3.13.2
- **Minecraft:** Java Edition 26.2
- **Host Java Runtime:** Java 26.0.2
- **Server Software:** [Paper 26.2](https://papermc.io/downloads/paper)
- **Bedrock Address:** `1moreblock.com:19132`
- **Client Compatibility:** Java players must use 26.2; Bedrock players can join with a version currently supported by [Geyser](https://geysermc.org/wiki/geyser/supported-versions/) via Geyser with Floodgate authentication
- **Host Hardware:** Apple M-series (M1, M2 Pro, M4 Pro)
- **Primary Game Modes:** Survival, Creative, OneBlock, Skyblock, Event worlds

### 🔌 Notable Plugins & Enhancements

- [LuckPerms](https://luckperms.net/) – Permissions management
- [CMI](https://www.zrips.net/cmi/) – Essentials, economy, admin utilities
- [Jobs Reborn](https://www.spigotmc.org/resources/jobs-reborn.4216/) – In-game jobs/economy
- [BentoBox](https://bentobox.world/) – Skyblock, OneBlock, and other island game modes
- [mcMMO](https://www.spigotmc.org/resources/mcmmo.2445/) – RPG skills system
- [WorldGuard](https://enginehub.org/worldguard/) & [WorldEdit](https://enginehub.org/worldedit/) – Region protection & building tools
- [DiscordSRV](https://scarsz.me/discordsrv) – Minecraft ↔ Discord chat bridge
- [Geyser](https://geysermc.org/) – Bedrock-to-Java protocol translation; [Floodgate](https://geysermc.org/wiki/floodgate/) – Bedrock account authentication
- [PyroFishingPro](https://www.spigotmc.org/resources/pyrofishingpro.82543/) – Advanced fishing system
- [PyroMining](https://www.spigotmc.org/resources/pyromining.82813/) – Mining overhaul/expansions
- [PyroFarming](https://www.spigotmc.org/resources/pyrofarming.85212/) – Farming rework
- [ShopGUI+](https://www.spigotmc.org/resources/shopgui.6515/) – Server shop/economy
- [NuVotifier](https://www.spigotmc.org/resources/nuvotifier.13449/) & [VotingPlugin](https://www.spigotmc.org/resources/votingplugin.15358/) – Vote rewards
- [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) – Placeholder integration for plugins
- [AnimatedScoreboard](https://www.spigotmc.org/resources/animatedscoreboard.20848/) – Dynamic scoreboards
- Many other custom scripts and public plugins!
